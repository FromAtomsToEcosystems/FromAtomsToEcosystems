How to read this guide: each row is one class meeting. Lesson days follow the same plan: warm-up (5–10 min) → lesson + Cornell notes (about 30 min) → worksheet (about 30 min) → exit ticket (10 min). Lab days are their own class meeting. Each unit after Unit 1 ends with a review day and a unit test; Unit 1 ends with a quick quiz on day 3. Units have been running about one extra day, so review days double as buffer days.
Materials on the site (updated Nov 18, 2026): ✓ done ○ not built yet. Lesson days track the lesson, Cornell notes, warm-up, exit ticket, worksheet, and slides; "Simulation" means interactive simulators built into the lesson. Lab days track the lab.
Built so far: Every unit is complete. Units 1–10: full sets for every lesson day (lesson, Cornell notes, warm-up, exit ticket, worksheet, slides), all virtual labs, a study guide and unit test (Versions A/B) for Units 2–10, and the Unit 1 Quick Quiz. Each unit also has a review game (practice, not graded). Every unit also has review stations and two more games: Sort Storm and the Physics Showdown team board. End of year: the Final Review and the Final Exam (Versions A/B). Still to build: Nothing on the plan. Everything is built.
