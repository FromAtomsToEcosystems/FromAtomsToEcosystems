2D Kinematics: Vectors

Physics, Unit 2: 2D Kinematics

Vectors in 2D

Add vectors tip to tail, use the Pythagorean theorem and SOH CAH TOA, and break vectors into components. Eight sections, about 60 minutes. Use the Calculator button at the top any time.

Objective

I can add vectors tip to tail, use the Pythagorean theorem and trigonometry to find a vector's size, components, and direction, and add vectors using components.

Standard

NGSS HS-PS2-1 (supporting). Analyze motion using mathematical representations. CCSS HSN-VM.A: represent and model with vector quantities.
