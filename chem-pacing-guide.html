Chemistry Pacing Guide

Chemistry · California NGSS · 85–90-minute alternating block (meets every other school day)
62unit class meetings
28flex meetings (unassigned)
90class meetings planned
How to read this guide: each row is one class meeting. Lesson days follow the same plan: warm-up (5–10 min) → lesson + Cornell notes (about 40 min) → worksheet (20–30 min) → exit ticket (10 min). Each lab is its own class meeting. The 28 flex meetings are kept unassigned for retakes, reteaching, lab write-ups, and semester finals.
Materials on the site (updated Nov 3, 2026): ✓ done ○ not built yet. Lesson days track the lesson, Cornell notes, warm-up, exit ticket, worksheet, and slides; lab days track the hands-on lab and its matching virtual lab.
Built so far: Unit 2: 6 of 11 lesson days have a full set, both labs (with virtual versions), review game, escape room, and vocabulary list. Unit 3: all 4 lesson days have a full set, both labs (with virtual versions), review game, escape room, Balancing Race, Card Sort, and Molecule Builder. Still to build: Unit 1, Unit 2 Families / Valence electrons / Comparing bonds, both unit tests, the Unit 3 vocabulary list, and Units 4 to 6.
